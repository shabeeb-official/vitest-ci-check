# 202510011536: PDP

- In PDP a single product is not returned an array of products is returned with
  the same `group_id`.
- Each of these list item will have the same `group_id` but a different `sku_id`
  which is essentially saying all of these products are different.
- At any given time only one product from this will be displayed to the user
  this is taken by `sku_id`.
- At the same time there is a need for all the colors & sizes that the
  particular `group_id`, this is a challenge this needs to overcome
- The solution was to loop through every product in the array and for each color
  create a new key in a object which have an array of sizes inside. 
- Sizes array is populated in the same way and adding the `sku_id` and `size` to
  the field with color, so by this logic color is the primary selector and for
  each color there will be multiple sizes
