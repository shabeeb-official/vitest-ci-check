## PDP Colors

- Since the PDP is having a list of products it is necessary to go through each
  of the products and find the colors.
- For each unique color it is added into a temporary object as keys, this
  approach helps to only have unique colors because an object cannot have
  duplicate keys
- After going through the entire array return the colors object

The color object is the most important part of the PDP because sizes can only be
selected after color is selected, See [Size PDP](202510011536-size-pdp.md) for
details on sizes.
