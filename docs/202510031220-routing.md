# 202510031220: Routing

We use a **HashRouter** instead of a **BrowserRouter** because the frontend is
deployed as a static bundle loaded via a **loader script** and embedded in a
host website. 

### Why HashRouter
- BrowserRouter requires server configuration to handle routes, which is not
  possible in a static-hosting scenario.
- HashRouter merges routing entirely on the frontend using `#` fragment,
  eliminating the need for backend route handling
