# 202510011420: PDP

In PDP there is a issue related to sizes in which a single product will have
repetitive sizes.

This is due to the list of products which is retrieved have multiple `sku_ids`
which have the same sizes. Why this is an issue is because we are taking colors
first and adding sizes which have the same color into an object See
[References](#references) for more details on this. 

We cannot remove the duplicate sizes because each size have different
`sku_ids`, so removing any particular entry means that a product is removed.


### Sample product group_id to recreate this issue
1. 20195827
