# 202509301105: Frontend

The front-end is developed in **React** and distributed as a **library** for
embedding on host websites.

- Deployed via a **Google Cloud Bucket**.
- The compiled app output as a [library](202509301119-building-as-library.md).
- A **loader script** in the host websites fetches the library and mounts it.
